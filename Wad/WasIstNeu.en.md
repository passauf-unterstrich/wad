# Wad 1.3.0
Hi, here’s what’s new:
- **Input Language:** The “Language” menu is now called “Input Language”.
- **New input languages:** Japanese, Finnish, Chinese, and Swahili.
- **Menu Language:** Wad now speaks English, German, and Japanese. Switch under “Menu Language” in the menu, instantly, no restart needed.
- **New installs:** Wad now starts in English. If you already use Wad, it stays in German.
