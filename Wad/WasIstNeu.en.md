# Wad 1.3.0
Hi, here’s what’s new:
- **Input Language:** The “Language” menu is now called “Input Language”.
- **New input languages:** Japanese, Finnish, Chinese, and Swahili.
- **Menu Language:** Wad’s menus now come in English, German, and Japanese. Switch under “Menu Language” in the menu, instantly, no restart needed.
- **New installs:** Wad now starts with an English menu, and the input language follows your Mac’s language. If you already use Wad, everything stays as it is.
